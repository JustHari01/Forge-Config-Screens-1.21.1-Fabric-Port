# Forge Config Screens Unofficial Port

Unofficial Fabric port of Forge Config Screens for Minecraft 1.21.1. It provides in-game screens for editing configuration files exposed through Forge Config API Port.

## Requirements

- Minecraft 1.21.1
- Fabric Loader 0.16.14 or newer
- Fabric API 0.116.17 or newer
- Forge Config API Port 21.1.6 or newer
- Mod Menu 11.0.0 or newer
